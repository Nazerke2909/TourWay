TourWay — Travel Agency Landing Page

1. Project Overview

TourWay is a travel agency landing page designed to help users discover destinations and explore travel packages.

The main idea of the project is to create a modern, attractive, and user-friendly website where visitors can find travel inspiration and learn about different holiday options.

Tagline: Explore the World Your Way.

2. Design Reference

The website was created based on a design in Figma.

Figma Design: TourWay — Travel Agency Landing Page

Design Style: Modern, premium, and editorial

Main Colors: Navy, warm off-white, sage green, and terracotta

Typography: Playfair Display and Inter

4. Website Sections

The landing page contains the following sections:

Header — navigation and website logo.

Hero Section — main travel image and introductory message.

Destination Search — search form for travel destinations.

Popular Destinations — Bali, Santorini, Kyoto, and Swiss Alps.

Why Choose Us — information about the advantages of TourWay.

Featured Packages — travel packages with prices and descriptions.

Testimonials — customer reviews and ratings.

Call to Action — promotional section encouraging users to explore trips.

Footer — additional website information.

5. Project Versions

The project has two development versions.

V1 — Initial Implementation

Created the main website structure.

Implemented the Figma design using HTML and CSS.

Added images and SVG icons.

Added responsive layouts.

Implemented basic JavaScript interactions.

V2 — Improved Implementation

Improved keyboard accessibility and visible focus states.

Improved the tablet search layout.

Added image dimensions and loading optimization.

Added accessible travel package detail dialogs.

Improved mobile navigation keyboard behavior.

Added support for reduced motion preferences.

Removed placeholder social and legal links.

7. Accessibility and Performance

The project includes several improvements:

Visible keyboard focus indicators.

Keyboard support for dialogs and navigation.

Lazy loading for images below the first screen.

High-priority loading for the hero image.

Reduced motion support.

Improved image dimensions to reduce layout shifts.

9. How to Run the Project

Clone the repository:

git clone https://github.com/Nazerke2909/TourWay.git

Open the project folder in VS Code.

Start a local server:

python -m http.server 5500

Open the following address in your browser:

http://localhost:5500
